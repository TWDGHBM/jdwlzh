# Joe Dever's Lone Wolf HD Remastered Windows 汉化补丁

《Joe Dever's Lone Wolf HD Remastered》（Steam AppID 279440）个人简体中文补丁。


> **本仓库不包含游戏本体。** 仅提供安装脚本、校验值与差分数据，使用时需自备正版游戏。
> 适用版本：Steam 英文原版 · buildid **510115**（2022-04-02）· Unity 4.5.4f1

## 下载

前往 [Releases](../../releases) 下载 **`LoneWolf汉化.zip`**（约 86 MB）

## 安装

1. 解压得到 `LoneWolf汉化` 文件夹，整个放进**游戏根目录**（与 `lonewolf.exe` 同级）；
2. 双击 `安装汉化.bat`，等待 10–30 秒（窗口显示进度）；
3. **从 Steam 启动游戏** → Options → Language → 中文。

安装前会校验 `resources.assets` 是否等于英文原版（`91457bf6…`）；不匹配直接退出，不改动任何文件。

## 卸载

双击 `卸载汉化.bat`。备份丢失时用 Steam「验证文件完整性」还原。
